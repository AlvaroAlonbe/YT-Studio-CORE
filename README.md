# YT Studio CORE

Aplicación Windows nativa Win32 + WebView2 para YouTube, descarga y edición de video.

## Arquitectura validada
- Win32 C++ x64
- Microsoft WebView2 como motor embebido
- Interfaz propia YT Studio CORE
- Editor local
- yt-dlp + FFmpeg
- Real-ESRGAN
- DPI PerMonitorV2

## Compilación
La compilación oficial se realiza con GitHub Actions en una máquina Windows limpia. El resultado se publica como artifact descargable del workflow.

Base actual: **v2.4.1**
